# 🎵 ARTISTAS E MÚSICAS

## 📌 Sobre o projeto

O projeto **Artistas e Músicas** tem como objetivo transformar um site estático em um sistema web dinâmico, utilizando HTML, CSS, PHP e MySQL.

O trabalho faz parte das atividades do semestre e permite colocar em prática os conhecimentos adquiridos nas disciplinas de LIMA e Banco de Dados.

## 🎯 Objetivo

Desenvolver um sistema web integrado a um banco de dados, permitindo o gerenciamento de informações sobre artistas e músicas.

## 🚀 Funcionalidades

- 🔐 Sistema de login e autenticação.
- 👤 Controle de sessões e acesso de usuários.
- 📝 Cadastro de artistas e músicas.
- 🔎 Consulta de informações.
- ✏️ Edição de registros.
- 🗑️ Exclusão de registros.
- 🖼️ Upload de imagens.
- 🗄️ Integração com banco de dados MySQL.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- PHP
- MySQL
- MySQL Workbench
